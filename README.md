# SentinelPH — Dengue Risk Monitor

A multi-agent dengue intelligence platform for the Philippines. SentinelPH ingests 12 years of surveillance data, weather records, news, and Google Trends signal; runs a risk scoring model; generates AI-written situation briefings; and surfaces everything through a public dashboard with a map, trend charts, and a RAG-powered chat interface.

> **Live demo:** *[(link added after deployment)](https://sentinel-ph.streamlit.app/)*
>
> **Data period:** 2012–2023 — historical records only, not real-time surveillance.

---

## What it does

| Feature | Description |
|---|---|
| **Risk Monitor** | Seasonal risk level (HIGH / MODERATE / LOW) computed from 12 years of national case patterns |
| **Regional Map** | Bubble map of dengue burden across all 17 Philippine regions |
| **Explore Data** | Year-range slider over the full weekly case history with peak-week metrics |
| **Ask AI** | RAG chat grounded in WHO dengue guidelines and Philippine health research — every answer is citation-enforced and fact-checked by a validator agent |
| **Prevention Tips** | Plain-language prevention guide |
| **AI Situation Report** | On-demand AI briefing for any historical week, generated by a 4-node LangGraph agent workflow and automatically evaluated before display |

```
  Open-Meteo ERA5  ──┤
  GDELT news       ──┼──► Parquet + SQLite ──┬──► XGBoost Risk Model
  Google Trends    ──┤                        ├──► LangGraph Agent Workflow
  GADM GeoJSON     ──┘                        └──► RAG Layer (ChromaDB)
                                                         │

```

**Stack**

| Layer | Tools |
|---|---|
| Language | Python 3.11 |
| LLM inference | Groq API (Llama 3.3 70B) — free tier |
| Agent orchestration | LangGraph |
| RAG | LangChain + ChromaDB + BAAI/bge-small-en-v1.5 |

| Dashboard | Streamlit |
| Map | Plotly Scattermap (carto-darkmatter tiles) |
| Data | OpenDengue V1.3, Open-Meteo ERA5, GDELT, pytrends |
| Deployment | Streamlit Community Cloud |

## Risk Model

- **Features (25):** Case lags at 1/2/4/8 weeks, 4-week rolling mean, weather lags (temperature, rainfall, humidity at lag 1–2), Google Trends signal, news count, epiweek, month, rainy-season flag
- **Target:** `log1p(national_cases)` of the following week
- **Temporal split:** train 2012–2020 · val 2021 · test 2022–2023
- **Test RMSE:** 0.70 (log) / ~979 cases — vs ARIMA 1.07 / Naive 1.18

---

## RAG Layer

- **Corpus:** 8 text-extractable PDFs — WHO Dengue Guidelines (2009, 2012), WHO Technical Handbook, clinical guidelines from PH and Timor-Leste, three peer-reviewed research papers
- **Index:** 1,617 chunks · BAAI/bge-small-en-v1.5 embeddings · ChromaDB
- **Validation:** A separate LangGraph node audits every answer for inline citations before it reaches the user

---

## Limitations

This is a monitoring and risk-scoring platform, not a prediction system or medical service.

- **Not real-time.** Data runs through 2023. The dashboard shows seasonal historical patterns, not live outbreak status.
- **National granularity only.** Province and city-level breakdown is not available in the OpenDengue V1.3 Philippines dataset at useful temporal resolution.
- **Risk scores are not diagnoses.** The XGBoost model identifies statistical correlations between weather/trend signals and case counts. It does not determine causation.
- **AI briefings are generated from historical data.** They are fact-checked by a validator agent, but they are not a substitute for official DOH or WHO communications.
- **Free-tier latency.** Cold starts on Streamlit Community Cloud take 3–5 minutes (PyTorch CPU + sentence-transformers install). Groq API response time is fast once warm.

## Running locally

**Prerequisites:** Python 3.11+, [uv](https://github.com/astral-sh/uv), a Groq API key (free at [console.groq.com](https://console.groq.com))

```bash
git clone https://github.com/aces-14/sentinel-ph.git
cd sentinel-ph

uv venv
uv sync

cp .env.example .env
# Edit .env and add your GROQ_API_KEY

streamlit run src/dashboard/app.py
```

The repository includes all processed data files, the trained model, and the ChromaDB index — no re-ingestion or re-training needed to run the dashboard.

**Re-running the agent workflow (optional):**
```bash
python -m src.agents.weekly_run --date 2023-10-01 --save
```

**Running tests:**
```bash
pytest tests/ -v
# 109 tests, all passing
```

## Data sources

| Dataset | Source | Coverage |
|---|---|---|
| Dengue case counts | [OpenDengue V1.3](https://github.com/OpenDengue/master-repo) | Philippines, 2012–2023 (national weekly) |
| Weather | [Open-Meteo ERA5](https://open-meteo.com) | 18 regions, daily, 2012–2023 |
| News | [GDELT Doc 2.0](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/) | "dengue Philippines", 2017–2023 |
| Search trends | Google Trends via pytrends | Philippines, weekly, 2012–2023 |
| Regional boundaries | [GADM 4.1](https://gadm.org) | 81 province polygons |
| RAG corpus | WHO, DOH, peer-reviewed journals | 8 PDFs, 406 pages, 1,617 chunks |
